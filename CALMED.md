# Calmed projects

Repos that use calm, by kind (see [`ADOPTING.md`](./ADOPTING.md) and the Constitution, Amendment 7).
A project appears only once it is real; this is never a wishlist.

## Full calm

Opted in to calm as law, with any departure written down as a scoped exception.

- **[calm-firefox](https://github.com/therealshakil/calm-firefox)** — a calm skin for Firefox: a static
  theme, a declutter stylesheet and calm prefs, for any OS. No exceptions.
- **[calm-desktop](https://github.com/therealshakil/calm-desktop)** — the calm desktop for a Linux Mint
  Cinnamon laptop: themes, icons, a slim bar and dock, light / mixed / dark. No exceptions.
- **[calm-wallpapers](https://github.com/therealshakil/calm-wallpapers)** — a small, hand-made set of
  monochrome desktop wallpapers. Exceptions: calm colour, research-earned; hand-use of Midjourney.
- **calm-lg-remote** (private) — a soft, colourful LG webOS TV remote for a child. Exception: colour — a
  low-arousal kids' skin (coquette / basketball / night) over the monochrome.

## Built on calm

Takes the layers it names; its own rules for the rest.

- **reverie** (private) — a self-curating poetry gallery; the poem is the art, the image born from the
  poem. Takes the method, voice and mechanics; its own identity (a 90s skate-zine register, marker-orange
  spot).
- **dotfiles** (private) — the machine handover: HANDOFF.md holds the facts, SETUP.md runs a
  choices-up-front, resumable installer through a `claude` session. Takes the method, voice, markdown
  rules and mechanics; no visual surface.
