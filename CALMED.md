# Calmed projects

Repos that have added calm — inheriting this suite's Constitution, identity, and voice through the
one-file `CLAUDE.md` pointer (see [`ADOPTING.md`](./ADOPTING.md)). The family at a glance. A project
appears only once it is real; this is never a wishlist.

- **[calm-wallpapers](https://github.com/therealshakil/calm-wallpapers)** — a small, hand-made set of
  monochrome desktop wallpapers. Borrows the Constitution, identity, and voice, with one scoped,
  research-earned colour exception.
- **calm-lg-remote** (private) — a soft, colourful LG webOS TV remote for a child. Borrows the
  Constitution, identity, and voice; runs a sanctioned scoped colour exception — a low-arousal kids' skin
  (coquette / basketball / night) over the monochrome.
- **dotfiles** (private) — the machine handover: HANDOFF.md holds the facts, SETUP.md runs a
  choices-up-front, resumable installer through a `claude` session. Borrows the Constitution, voice,
  markdown rules, and CLI conventions; no visual surface, so no tokens.
- **reverie** (private) — a self-curating poetry gallery; the poem is the art, the image born from the
  poem. Borrows the Constitution, voice, and CLI conventions; runs its own research-backed identity (a 90s
  skate-zine register, marker-orange spot) as a scoped exception to the monochrome.
