# Contributing

calm is shared to read, to use and to fork. That's the main way to take part: make it yours.

Issues are open. If something's broken, unclear, or you've built something with calm, you're welcome to
say so. There's no promise of a reply, a fix or a merge, and no timeline. An issue waits without a sound
until there's room for it, and that's how it's meant to work.

Pull requests are read the same way. Some may be taken; most probably won't, because calm changes slowly
and by its own rules (the [Constitution](./CONSTITUTION.md), and the Build Gate in [`CLAUDE.md`](./CLAUDE.md)).
A fork is never a lesser path.

How calm itself is developed in the open: [`docs/specs/014-calm-in-the-open.md`](./docs/specs/014-calm-in-the-open.md).
