# Welcome to calm

## How We Use Claude

Mostly planning and design (specs, research, the identity), then building features against a locked spec.

## Your Setup Checklist

### Codebases
- [ ] calm — https://github.com/therealshakil/calm

### MCP Servers to Activate
- [ ] None required — the team works without MCP servers right now.

### Skills to Know About
- calm-ds — the calm design system; load it for any visual or design work (artifacts, mockups, UI, copy). It sets the look: monochrome ink-on-paper, one clay accent, four locked faces.
- calm-council — convenes independent advisor personas to stress-test a hard-to-reverse decision before it's locked. Say "council this" or "debate this".
- drift — generates calm ASCII art (wordmarks, banners, textures) for docs and READMEs.
