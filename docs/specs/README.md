# Suite specs & spec-drops

**A spec lives with what it governs.** App specs sit under `apps/<app>/docs/specs/`; a foundation's spec
sits with the foundation (the terminal's is in `assets/terminal/`). This folder is the **cross-suite index**
plus the **spec-drops** that aren't tied to any one tool. Format + flow:
[`../spec-template.md`](../spec-template.md); every spec is research-backed
([`../research.md`](../research.md)) and ends with the Constitution Check.
